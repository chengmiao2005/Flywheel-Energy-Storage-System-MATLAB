### 工程内的后缀是什么意思

M文件是MATLAB程序；SLX是可以打开的Simulink模型；CSV是原始数字；GZ是压缩后的CSV；MAT和FIG是MATLAB结果存档。JSON和审计脚本用于核对数据。ReviewBundle.zip是某次运行的结果回传包，不等于完整项目源码。

旧的CommonTerminal、BidirectionalConverter、NonidealSystem、RobustControl和EnergyDispatch等包是逐步迭代版本。日常从最新整合工程进入即可，排错或研究演变时再看历史版本。
