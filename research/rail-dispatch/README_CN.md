## 我研究了什么

研究的问题是：**已经有飞轮储能和电压反馈控制时，再利用一份提前冻结的名义时刻表，能否进一步减少供电能耗？**

模型包含两列列车、2750 m 合成线路、一个集总直流节点、电源、制动电阻和飞轮储能。时刻表提供未来再生制动的机会信号，控制器据此提前放电，为即将到来的制动能量腾出空间。

公平比较的关键是：两种控制器使用相同储能装置、相同场景和相同参数搜索预算；运行结束后，再执行相同的 194 s 储能恢复过程，把最终储能和电压恢复到共同目标。恢复过程的电源与转换损耗也计入总能耗。

## 主要结果

| 指标 | 结果 |
| --- | --- |
| 独立合成场景 | 100 个 |
| 平均完整过程电源节能 | 0.082727 kWh |
| 场景平均值的近似 95% 区间 | [0.075187, 0.090268] kWh |
| 相对基准平均电源能耗 | 约 0.099% |

这是**相同储能装置上增加调度功能的微小增益**，不能写成安装飞轮系统的总节能率。1200 条仿真记录包含控制器、初始 SOC 和步长重复，独立统计样本仍是 100 个场景。

后续七个开发场景的诊断还保留了不利结果：降低实际转换效率时出现负收益场景；只比较运行阶段与计入最终恢复，控制器排序可能改变；20 s 单一预测窗口已保留当前四窗口方案的收益。这些诊断不构成新的独立测试。
